# Code of conduct

## The short version

Be decent. This is a small plugin that people run on their own machines, often to point a camera
or a screen at a model, so the bar that matters most is simple: don't make anyone's setup less
safe, and don't make contributing unpleasant.

## Expected behaviour

- Assume good faith and keep it technical. Critique the code, not the person.
- Respect privacy. Never post someone else's screenshots, window titles, logs, paths, API keys or
  personal data — in issues, PRs or comments.
- Accept a "no" on scope. A change that needs a desktop-app patch or a new dependency is a
  design conversation, not a bug in the reviewer.
- Say what you actually verified. "Unit-tested only" is a fine answer; a confident claim that
  was not checked is not.

## Unacceptable behaviour

- Harassment, insults, slurs, or personal attacks of any kind.
- Sexualised or violent content in project spaces.
- Publishing someone's private information without their explicit permission.
- Deliberately degrading the plugin for its users — hidden network calls, telemetry, or a
  dependency that exfiltrates captured content or descriptions. This is an immediate ban and will
  be reported.

## Scope

This applies to everything in this repository's spaces: issues, pull requests, review comments,
commit messages and discussions.

## Enforcement

Report a problem to the maintainer via GitHub — open a private security advisory (see
[SECURITY.md](SECURITY.md)) if the report itself is sensitive, or contact the maintainer directly
through their GitHub profile. Reports are read by the maintainer and kept confidential.

Possible outcomes, applied in good faith and in proportion: a private word; closing or locking the
thread; a temporary block; a permanent ban. The maintainer's decision is final.
